## 标准报名正文

以下各字段的标签与内容位于同一行，仓库链接使用普通 URL，不使用 Markdown 链接。创建或编辑 Issue 时仅复制四行正文：

```text
【参赛申请】
项目名称：麦合拍MaiMate
项目地址：https://github.com/Garyisthebest/MaiMate
项目简介：微信里的麦当劳点餐搭子，使用官方MCP查询真实门店、菜单与价格；通过可纠正的本地口味记忆、用户教会的餐品昵称和餐后反馈越用越懂你，明确确认后创建待支付订单并交接官方收银台。
```

Issue 提交和编辑不等于报名成功；只有活动官方回复审核通过后，才可认定通过该次审核。项目需保持公开可访问。获奖后的邮箱授权与兑奖资料应由本人通过官方渠道处理，不放入公开仓库或报名 Issue。
